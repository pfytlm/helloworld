# HelloWorld - OpenClaw Edition

这是一个由 OpenClaw 生成的简单 HelloWorld 网页项目。

## 功能特性

- 简单的 HTML 和 CSS 实现
- 响应式设计，适配多种设备
- 交互式问候功能
- 现代化的界面风格

## 文件说明

- `index.html` - 主要的 HTML 文件，包含页面结构和交互逻辑
- `README.md` - 项目说明文档

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 点击 "点击问候" 按钮
3. 输入您的名字，点击确定

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
